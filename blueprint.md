# Lotto Number Generator

## Overview

This is a simple web application that generates random lottery numbers.

## Current Task: Initial Setup

*   **Objective:** Create the basic HTML structure, CSS styling, and JavaScript logic for the lottery number generator.
*   **HTML:**
    *   Set up the main container for the application.
    *   Add a title.
    *   Create a display area for the generated numbers.
    *   Add a button to generate the numbers.
*   **CSS:**
    *   Style the container, title, number display, and button for a clean and modern look.
*   **JavaScript:**
    *   Implement a function to generate 6 unique random numbers between 1 and 45.
    *   Attach an event listener to the button to call the generation function and update the display.
